Community contribution

Know a dataset or model that isn't listed?

The Atlas is only as complete as the community that feeds it. Adding an asset takes about five minutes and helps the next researcher skip a week of searching.

Open a GitHub issue Use the submission form
  1. 1

    Check it isn't already listed

    Search the directory above by name or language to avoid duplicates.

  2. 2

    Gather the essentials

    Asset name, language(s), task type, format, license, and a direct link to the source (GitHub, Hugging Face, or paper).

  3. 3

    File it through GitHub or the form

    The GitHub issue template pre-fills the fields below; the form works if you'd rather not use GitHub.

  4. 4

    A maintainer reviews and merges

    Entries are checked for a working link and accurate metadata, then added to the directory.

.github/ISSUE_TEMPLATE/new-asset.yml — fields required

name: Asset title

language: One or more African languages

task: Dataset / Model / Benchmark / TTS / STT / MT

source_url: GitHub, Hugging Face, or paper link

format: e.g. CoNLL, JSON, WAV, safetensors

license: e.g. CC-BY-4.0, MIT, unspecified
